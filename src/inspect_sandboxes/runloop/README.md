# Runloop Sandbox

Cloud development environment sandbox for [Inspect AI](https://inspect.aisi.org.uk/) using [Runloop](https://www.runloop.ai/).

For setup, configuration, and usage, see the [Runloop provider page](https://meridianlabs-ai.github.io/inspect_sandboxes/runloop.html) on the [`inspect_sandboxes` documentation site](https://meridianlabs-ai.github.io/inspect_sandboxes/).
