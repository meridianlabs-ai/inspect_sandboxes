# Novita Sandbox

For setup, configuration, and usage, see the [Novita provider page](https://meridianlabs-ai.github.io/inspect_sandboxes/novita.html) on the [`inspect_sandboxes` documentation site](https://meridianlabs-ai.github.io/inspect_sandboxes/).
